# SCUT-school-logo-detect
已完成利用神经网络实现SCUT校徽的识别功能，实验步骤如下（纯人工）：
1准备训练集：利用手机拍摄不同角度下的校徽图片，共计60张，利用labelImg软件绘制真实框，按照8：2的比例以txt的格式存放于logo-label文件夹
2编写神经网络训练（train.py)：利用yolov8模型，读取路径内文件，对图片进行前向传播，反向传播，计算损失函数，最后得到拟合模型存放于根项目文件夹，本实验定义epochs=200，即进行200次训练，patience=30。
3编写实时部署的摄像头识别（camera_detect.py）：用OpenCV打开电脑摄像头，一帧一帧读取画面，缩放到640×640，并进行归一化，按confidence排序，保留最高的，删除与它IoU重叠度大于0.45的框。最终只剩下一个最准确的框，对视频的每一帧重复2~6步，直到按下“q”退出
4实验结果：训练的模型实际maP达到0.995，证明训练效果优秀（nice），根据溯源，总计训练60分钟。实际运行epochs194次，利用camera_detect可以实时检测校徽位置如视频所示
5附录：文件源存放于datasets文件夹中，实际训练结果拟合曲线及训练结果被创建于runs文件夹中，我是遐蝶大人的狗，项目已上传至GitHub上开源
6文件夹中的bat文件均为快速打开程序的入口
